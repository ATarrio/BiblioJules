# Data Safety Form for BiblioJules (Google Play Console)

## What data is collected by BiblioJules?
- **None.** The app does not collect any personal data, usage statistics, or analytics.

## What data is shared with third parties?
- **None.** BiblioJules does not share data with third parties.

## Data collected by BiblioJules (the developer)
- **None.** BiblioJules does not collect, store, or process any data.
- The developer of BiblioJules does not run a service, host accounts, or store passwords.

## Data collected by your server (if you sync)
- **Only the data you choose to sync** (e.g., book titles, loan status, user notes) when using the sync feature.
- **Your server also holds user accounts and passwords** if you configure authentication.
- This is handled by your server, not by BiblioJules.

## Data processing location
- All data remains on your device in local mode.
- When syncing, data is processed on your server (which you control).

## Data encryption
- **In transit**: HTTPS is required (`android:usesCleartextTraffic="false"`).
- **At rest**: Depends on your server's configuration.

## Data security
- No data is stored or transmitted by BiblioJules.
- Your server is responsible for data security if you use sync mode.

## Account deletion
- **BiblioJules does not manage accounts.**
- If you use sync mode, account deletion is handled by your server.
- If you use local mode only, delete the app's local storage in Android Settings.

## Other data considerations
- **No ads** are shown in the app.
- **No tracking** is implemented.
- **No third-party analytics** are used.
- **No location data** is collected.
- **No device identifiers** are collected or used.
- **No advertising identifiers** are collected or used.
- **Camera access** is only for barcode scanning (local processing), not for sending images to external services.

## Data safety statement for Play Console
> BiblioJules (the developer / app) does not collect, store, or process any user data, accounts, or passwords. The app connects to a user-provided server for sync; that server (which you operate or control) stores user data, accounts, and passwords. All data remains on the device unless the user syncs to their own server. Account deletion is managed by the user's server, not BiblioJules. No data is collected, processed, or shared by BiblioJules as a service.
