{#- The colours every page paints with, from app/themes.json. Two halves, both rendered server-side from the browser's cookie so there is never a flash of the previous theme: * ``brand`` — the accent, as real colours; * ``slate`` — the surfaces, as CSS variables. The ramp is slate's lighting rotated onto the theme's hue, so a single ``bg-slate-900`` class is a deep tinted panel in dark mode and a pale one in light mode, and contrast stays exactly where it was. ``card`` is the light-mode panel colour (near-white, faintly tinted); in dark mode the panels use the ``900`` step, like they always have. Included by base.html and by the standalone sign-in page, which renders its own . -#}
